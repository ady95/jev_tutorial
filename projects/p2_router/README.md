# 프로젝트 2 — AI Model Router

책의 08-2에 대응합니다.

난이도와 민감도를 판정해 두 등급(`fast` = 하위 티어, `strong` = 프런티어) 중 하나로
보내고, **절감액과 품질을 함께 잽니다.**

```bash
python projects/p2_router/router.py
```

`.env` 에 `OPENAI_MODEL_SMALL` 과 `OPENAI_MODEL_FRONTIER` 를 따로 지정해야 두 등급이
실제로 다른 모델이 됩니다 (`.env.example` 참고).

## 시작 전에

이 프로젝트는 **정확도를 올리는 프로젝트가 아닙니다.** 책의 6부 실측(과제당 3건)에서
모델 다섯 개가 두 과제를 모두 맞혔습니다. 목표는 같은 정확도를 더 싸게 얻는 것입니다.

`router.py` 의 `PRICES` 를 여러분의 계약 단가로 채워야 절감액 계산이 의미를 갖습니다.

## 절감액의 기준선

"전부 프런티어로 보냈다면 얼마였나"는 **싼 모델의 토큰에 프런티어 단가를 곱해서
구하면 안 됩니다.** 모델마다 출력 길이가 달라서, 실제로는 비용이 늘었는데 절감으로
보일 수 있습니다. `audit()` 이 싼 모델로 간 건 일부를 프런티어로 다시 돌리고, 그때
남긴 토큰 기록(`shadow`)으로 `savings_report()` 가 기준선을 계산합니다.

## 반드시 함께 돌릴 것

- `survey()` — 트래픽의 난이도 분포. 쉬운 질문이 적으면 만들지 마세요
- `audit()` — 싼 모델로 보낸 건의 표본 감사. 품질 비교와 비용 기준선을 함께 만듭니다
