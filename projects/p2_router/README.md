# 프로젝트 2 — AI Model Router

책의 08-2에 대응합니다. 난이도 별 둘.

난이도와 민감도를 판정해 알맞은 등급의 모델로 보내고, **절감액과 품질을 함께 잽니다.**

```bash
python projects/p2_router/router.py
```

## 시작 전에

이 프로젝트는 **정확도를 올리는 프로젝트가 아닙니다.** 책의 실측에서 모델 다섯 개가
같은 과제를 모두 맞혔습니다. 목표는 같은 정확도를 더 싸게 얻는 것입니다.

`router.py` 의 `PRICES` 를 여러분의 계약 단가로 채워야 절감액 계산이 의미를 갖습니다.

## 반드시 함께 돌릴 것

- `survey()` — 트래픽의 난이도 분포. 쉬운 질문이 적으면 만들지 마세요
- `audit()` — 싼 모델로 보낸 건의 표본 감사. 비용 절감은 보이고 품질 저하는 안 보입니다
