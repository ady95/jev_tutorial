# ch11 — 기권할 수 있는 시스템 (11부)

11부는 **전자책 전용** 장입니다. 코드는 여기 전부 공개되어 있고,
만드는 과정과 해설이 전자책에 있습니다.

| 파일 | 책의 절 | 무엇을 하나 | API 호출 |
|---|---|---|---|
| `01_abstain_signals.py` | 11-2 | 기권 신호 5종을 같은 호출에서 받아 분리력 비교 | 60회 |
| `02_reliability_stats.py` | 11-3 | 측정값과 주장 가능한 하한을 구분, 필요 표본 계산 | 없음 |
| `03_audit_sampling.py` | 11-4 | 표본 점검 큐 설계와 누적 시뮬레이션 | 없음 |
| `04_improve_criteria.py` | 11-5 | criteria 개선 전후 비교 | 120회 |

`02`와 `03`은 먼저 `ch04/calibration.py` 를 실행해 `out/calibration.json` 을 만들어야 합니다.

## 이 장의 요지

책에서 시도한 다섯 가지 중 넷이 실패했습니다.

```
메타 질문으로 기권 신호 만들기    실패 (분리력 +0.03 ~ +0.09)
LLM 합의로 게이팅                실패 (신뢰도 0.737)
게이트 통과 건 교차 검증          실패 (잡은 것 0건)
margin을 보조 신호로             부분 성공
후보 정의 고치기                 성공 (0.95 기준 coverage +11.6%p)
```

`01_abstain_signals.py` 를 여러분의 데이터로 돌려보시기 바랍니다.
**분리력을 재지 않으면 효과 없는 질문에 토큰을 계속 쓰게 됩니다.**
